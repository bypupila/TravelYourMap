# Non-canonical TravelMap implementation

This folder is an alternate Supabase implementation kept for reference and local development.

- Production is deployed from `../web`.
- Do not link this directory to the `youmap` Vercel project.
- Database and billing changes in this variant must not be applied to the production Neon stack.

The local Vercel link was intentionally removed on 2026-07-13 to prevent accidental production overwrites.
